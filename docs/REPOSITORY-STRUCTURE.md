# Portfolio structure & maintenance

## Active entry points
- `index.html`: main portfolio.
- `home-preview.html`: intro preview.
- `pages/project-detail.html`: WebMotion project story.
- `pages/design-detail.html`: WebMotion screenshot gallery and explanations.

## Active source
- `src/css/studio.css`: shared styles.
- `src/css/intro.css`: intro styles.
- `src/js/fit.js`: viewport fitting helper.
- `src/js/intro.js`: intro sequence.
- `src/js/main.js`: collection rendering and portfolio interactions.
- `src/js/motion.js`: motion behavior.

## WebMotion screenshots
Store original screenshots in `assets/webmotion/screenshots/` with ordered descriptive names. Pair each image with its own explanation in the Design Detail page. Do not use fabricated mockups or stock screenshots.

## Legacy
`src/css/legacy-style.css` is retained for reference and is not loaded by active pages.
